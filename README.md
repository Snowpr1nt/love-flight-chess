# 恋爱飞行计划 · 异地情侣真心话大冒险飞行棋

双人同屏网页游戏。两人从**同一个起点**进入 44 格回旋棋盘，沿途完成 18 道真心话、18 道大冒险，并经过 4 个奖励格与 4 个惩罚格。先精准抵达中央爱心终点的一方获胜，双方可写下最终约定。互动内容适合异地情侣通过文字、语音或视频完成，尺度为甜蜜轻暧昧。

[设计与规则](DESIGN.md) · [逐版修改记录](CHANGELOG.md) · [联网与微信接入设计](docs/ONLINE_DESIGN.md) · [联机协议草案](docs/ONLINE_PROTOCOL.md)

## 打开游戏

双击 [index.html](index.html) 即可离线游玩，无需安装依赖或注册账号。也可在项目文件夹中执行 `python -m http.server 8080`，然后打开 `http://localhost:8080/`。

当前 Demo 由两人在同一设备轮流操作；异地游玩可自行配合屏幕共享与通话工具。当前没有双端实时联机。

## 玩法

1. 输入双方昵称，系统随机决定先手。两枚棋子都停在棋盘右下侧的「共同起点」。
2. 尚未起飞时掷出 2、4、6，直接进入第 1 格；掷出 1、3、5 则换人。掷出 6 不额外获得一轮，也没有第三次保底起飞。
3. 起飞后每掷出一点就沿回旋路径移动一格。两枚棋子可以同格，彼此不相撞。
4. 普通格弹出真心话或大冒险卡，完成后点击「已完成」交棒。双方同意时可以换同类题或跳过。
5. 第 5、15、25、35 格奖励前进 2 格；第 10、20、30、40 格惩罚回退 2 格。先选现实奖励／惩罚并确认，再移动；新落点继续触发事件。双方也可跳过现实内容，棋盘位移照常执行。
6. 从第 44 格再前进一步进入中央爱心终点。必须精准抵达；掷骰越过终点时，棋子沿路线回退多余步数。获胜后可选择并保存双方同意的最终约定。

「36 张心动卡」可预览所有互动。进度、音效、记录与最终约定仅保存在当前浏览器本地；清除浏览器数据会丢失。默认静音，可在「游戏设置」开启掷骰与换人提示音。升级到 V4 后，旧版棋局不自动沿用，旧昵称和音效设置仍可预填，以免旧版蓝方第 23 格入口被误映射。

## 界面与动画

桌面优先采用横版：玩家状态位于棋盘上方，**10 列 × 8 行的双层回旋路径**占据主要空间；骰子与原有爱心终点位于中央，掷骰按钮、当前位置和下一位信息在棋盘右侧独立可见。窄屏转为 8 列 × 10 行，操作与状态移到棋盘下方，说明与日志可折叠。棋盘延续奶油色、粉色波点、紫色虚线与原创像素猫、草莓、爱心、水滴，格子使用手绘边线、纸感底纹、像素细节和更丰富的粉蓝黄紫配色。

骰点在动画启动前生成。骰子约经过 0.1 秒预备、0.96 秒滚动、0.3 秒减速、0.5 秒定格停顿；棋子随后每格滑行约 0.3 秒。奖惩二次位移沿相同路径播放。动画期间禁止重复操作，并支持系统的「减少动态效果」。

## 联机扩展

规则集中在 `engine.reduce(state, action)`，与界面分离。未来服务端可保存权威状态、校验双方动作并广播结果，现有棋盘和题卡界面可以复用。目前没有账号、录音或上传答案功能。

2026-10-19 已完成 [异地双人联机与微信接入设计 v1](docs/ONLINE_DESIGN.md)，涵盖双人私密房间、微信身份与头像授权、服务端掷骰和结算、实时事件、重连与分阶段开发。对应 [协议草案](docs/ONLINE_PROTOCOL.md) 明确命令、权限、幂等与恢复。当前交付仍为 V4 本地游戏；上述联网服务与真实微信登录尚未实现或部署。
