# 网页联机演示交付说明 · 2026-10-20

## 本次范围

公开首页、昵称头像体验身份、双人邀请与房主审核、双方准备、服务端掷骰与完整结算、同步动画、持久化与断线恢复。保留原 V4 手绘像素棋盘、36 个互动任务、共同起点和爱心终点。真实微信登录、微信头像自动获取与小程序尚未实现。

公开演示入口：https://love-flight-duo-demo.sunnylyric36.chatgpt.site

## 推荐验收顺序

1. 在两台设备或两个互相隔离的浏览器会话中打开网址，使用不同昵称和头像。
2. 甲创建房间；乙使用邀请链接申请加入。甲确认前，乙只能看到等待状态。
3. 甲批准申请，双方准备；查看双方头像、先手和等待状态。
4. 当前玩家掷骰，双方应看到相同最终点数、落点和任务。等待玩家不能掷骰或代为完成任务。
5. 完成或跳过任务，确认换人提示与粉蓝主题色；设置中可开启音效。
6. 任一方刷新、断网再恢复，应恢复原房间。断线期间不能继续推进棋局。
7. 奖惩格须先选择，再逐格移动并触发新落点；精确进入爱心终点后查看最终奖励；双方同意可再开一局。

## 实施方案调整

原设计文档作为历史方案保留。本次托管环境使用 Cloudflare Workers，因此实际后端采用 D1；同步使用约 1.1 秒的 HTTPS 拉取。后端仍是权威状态机，客户端提交意图，服务端验证席位、当前回合、matchId、revision 和动画锁定时间。骰点仅在服务端生成。

状态更新和命令回执在同一 D1 批处理中提交，通过 revision 条件更新拒绝竞争写入；重复 actionId 返回已有结果，同一 actionId 换内容则拒绝。重新开局更换 matchId，阻止旧命令误入新局。

客户端保留共享规则渲染、动画及平台适配边界，服务端入口与具体持久化适配分离，便于后续替换传输和账号系统。本地 SQLite 适配只用于开发和测试，线上使用托管 D1。

## 数据边界

- 体验身份使用当前浏览器的 HttpOnly Cookie。清除 Cookie 或换浏览器不会自动恢复该身份；当前无跨设备账号找回。
- 服务器保存昵称、压缩头像、房间成员、棋局、任务选择、回执和在线心跳。互动答案不上传；头像可能出现在获准加入者的界面中。
- 邀请码不等于成员权限，加入需要房主批准。写操作校验 Origin、JSON 类型和专用请求头；正文、头像、房间数量和请求频率设有上限。
- 等待房间 30 分钟、已开局房间 24 小时后停止访问；数据库定时清理和完整数据删除界面属于后续工作。
- 音效偏好和自定义最终约定文本仅保存在设备；最终奖励类型同步给双方。

## 验证记录

- 原棋局规则测试 15/15；联机服务测试 10/10，包括完整双人棋局到获胜、幂等、并发、断线、重启恢复、奖惩、越界、权限、邀请及头像边界。
- 独立子 Agent 复核后，修复命令入口绕过加入请求检查，以及移动中查看旧任务造成弹窗叠加的问题；均增加对应回归验证。
- 两个隔离浏览器实测：资料、邀请、审核、准备、双方骰子与任务一致、等待方只读、完成换人、刷新、断线恢复；上传图片裁剪压缩；奖惩移动弹窗时序。
- 1440px 桌面、390px 和 320px 手机布局实测；44 格可见，骰子、爱心终点、起点和操作信息无格子重叠，手机无横向溢出。
- Vinext / Cloudflare Workers 生产构建通过。线上发布结果及 Git 提交以交付消息与仓库记录为准。
